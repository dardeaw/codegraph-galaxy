# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We take the security of CodeGraph 3D seriously. If you discover a security vulnerability, please do NOT open a public issue.

Instead, please send an advisory email to `security@codegraph.dev` (or open a private GitHub Security Advisory). We will acknowledge receipt within 48 hours and work with you on a patch before public disclosure.
